

# Student Marks Calculator

A beginner-friendly Python project that calculates
student marks, total, average, and grades.

## Features
- Accepts student name
- Takes marks for 5 subjects
- Calculates total marks
- Calculates average
- Assigns grades automatically

## Technologies Used
- Python 3

## How to Run

1. Download the repository.
2. Open the terminal.
3. Run:

python marks_calculator.py
